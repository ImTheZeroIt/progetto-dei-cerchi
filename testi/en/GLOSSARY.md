# Translation brief — "Confederazione dei Cerchi" (Italian → English)

You are translating a corpus of constitutional and regulatory texts (a Constitution, 16 Codes, technical annexes) plus four essays. The same terms recur across 25 documents translated in parallel by several translators, so **terminology must be identical everywhere**. Use the glossary below without variation. If a term is not in the glossary, translate it naturally and consistently.

## Register and style

- British spelling (labour, offence, organisation, programme, centre).
- Legal-drafting register for the Constitution, Codes and annexes: precise, plain, complete sentences. Use **"shall"** for obligations, **"may"** for permissions, **"It is prohibited to …" / "… is prohibited"** for "È vietato …", "shall not" for negative duties. Definitions and descriptions stay in the present tense.
- The four essays (La storia umana, Analisi del presente, Il sistema contro l'individuo, Progetto dei Cerchi) are prose: translate faithfully, keeping the author's voice, rhythm and short one-line paragraphs. Do not embellish.
- Translate everything. Do not summarise, omit, merge, split or add sentences. Do not add translator's notes.
- Keep numbers exactly in the same form: digits stay digits, numbers written in words stay words (e.g. "novanta giorni" → "ninety days", "15 ore" → "15 hours"). Only the decimal/thousands separators change to English usage (9,9% → 9.9%; 18.300 → 18,300). Never convert units or magnitudes ("miliardi" → "billion", never trillion).
- Quotation marks «…» → “…”. Keep em dashes and en dashes as in the source.

## FILE FORMAT — the most important rule

Each source file is line-based. **The translation must have exactly the same number of lines as the source, and line N of the output must be the translation of line N of the source.** Never join two lines, never split one line, never drop or add a line (blank lines included).

Keep every structural marker at the start of a line exactly as it is, character for character:

| Line starts with | Meaning | Keep |
|---|---|---|
| `#1 `, `#2 `, `#3 ` | section heading | the marker; translate the rest |
| `#A Art. 12-bis — ` | article heading | `#A Art. 12-bis — ` exactly (same number); translate the title after the dash |
| `7. ` | numbered paragraph | the same number and `. `; translate the rest |
| four spaces + text | sub-paragraph of the paragraph above | the four spaces; if it begins with a letter marker like `a) ` keep the same letter |
| `::p ` or `::p[Style] ` | plain paragraph | the marker exactly, including any `[Style]`; translate the rest |
| `::p 4.9-bis. ` | Constitution paragraph with literal number | keep `::p 4.9-bis. ` exactly |
| `::p a) ` | Constitution letter | keep `::p a) ` exactly |
| `::raw 0` | embedded block | copy the line unchanged |
| `#`, `##`, `###` (Markdown files) | heading | same number of `#` |
| `- `, `> `, table rows with `\|` | Markdown list / quote / table | same marker, same number of `\|` cells |

Inside the text keep these inline markers: `**bold**` (same number of `**` pairs, around the corresponding words), `⏎` (line break), Markdown links `[text](url)` (translate the text, keep the URL unchanged).

Every digit in the source line must appear in the translated line (article numbers, paragraph numbers, versions, percentages, years). Do not renumber anything.
