Modello di sito

Il sito della vostra rete, Comunità di Base o Cerchio, senza programmare. Compilate le schede, guardate l'anteprima e scaricate il sito: è un solo file che si pubblica gratis dove volete, o si apre anche da una chiavetta.

Ogni sito è indipendente e si collega agli altri: al Cerchio superiore, alle comunità vicine. Non c'è un sito centrale. Il sito non raccoglie dati di chi lo visita e non usa servizi esterni. Pubblicate solo quello che la vostra assemblea ha deciso di rendere pubblico.

Chi siete

Una riga vuota fa un nuovo paragrafo. Le righe che cominciano con «- » diventano un elenco. Gli indirizzi web diventano collegamenti.

Scarica e pubblica

Il file del sito contiene anche i dati: per modificarlo più avanti basta riaprirlo qui con «Apri un sito già fatto».

Dove pubblicarlo, gratis

  1. GitHub Pages o Codeberg Pages: create un archivio (repository) con un account del gruppo, caricate il file index.html, attivate «Pages» nelle impostazioni. Il sito sarà a un indirizzo come nomegruppo.github.io/sito.
  2. Qualsiasi spazio web che ospita pagine semplici: il file non ha bisogno di nient'altro.
  3. Senza internet: copiatelo su una chiavetta o stampatelo dal browser (le pagine si stampano pulite).

Per aggiornarlo: riaprite il file qui, cambiate quello che serve, scaricatelo di nuovo e sostituite il vecchio.

Il file contiene anche i dati in forma leggibile dalle macchine: così un domani il sito del Cerchio superiore o il portale delle reti potranno mostrare le vostre decisioni e i vostri servizi senza un archivio centrale.

I dati restano in questo browser finché non li cancellate. Nessuno li riceve finché non pubblicate il sito.
