Change log

This is the first public version: Constitution V.29 and aligned Codes, published on 5 October 2026.

From here on, every accepted change will be recorded on this page with its date, the text and article concerned, and the reason.

Changes

19 October 2026 — C.1-Annex A, Art. 4, paras. 1 and 3, and new para. 1-bis; Code 1, Art. 32, new para. 1-bis (proposal 1)

Clothing and hygiene in the Material Basket. The accepted text is that of proposal 1, version 2.

Reason: Clothing and hygiene products are necessary for everyone, and no Basket named them.

Discussion: no comments received by 19 October 2026 (issue 9).

19 October 2026 — Code 1, new Art. 47-bis (proposal 2)

Standard of adequate dwelling. The accepted text is that of proposal 2, version 4.

Reason: The Constitution guarantees housing, but no text said what makes a dwelling adequate.

Discussion: no comments received by 19 October 2026 (issue 10).

19 October 2026 — Code 7, Art. 3, new para. 9; Code 5, Art. 2, new para. 4-bis (proposal 3)

Connectivity and learning materials. The accepted text is that of proposal 3, version 2.

Reason: Connectivity is a right, but Code 7 did not say with what it is exercised.

Discussion: no comments received by 19 October 2026 (issue 11).

19 October 2026 — Code 8, Art. 4, para. 4 (proposal 4)

First-application value of the Energy Basket. The accepted text is that of proposal 4, version 2.

Reason: The Energy Basket listed the guaranteed services without any minimum value.

Discussion: no comments received by 19 October 2026 (issue 12).

19 October 2026 — Code 1, Art. 43, new para. 1-bis (proposal 5)

CdR for cultural activities offered to the Community. The accepted text is that of proposal 5, version 2.

Reason: What a person offers to everyone is a contribution; counting by hours and the annual limit keep it from becoming a ranking.

Discussion: no comments received by 19 October 2026 (issue 13).

19 October 2026 — Code 10, Art. 1, paras. 1, 2 and 3; Art. 9, para. 1, letter a) (proposal 6)

Subsoil as a common good. The accepted text is that of proposal 6, version 2.

Reason: No text named the subsoil and deposits; now no rent can be drawn from them.

Discussion: no comments received by 19 October 2026 (issue 14).

19 October 2026 — Code 10, new Art. 8-bis and Arts. 3 and 7; Code 15, Art. 12, new para. 5-bis (proposal 7)

Raw materials: recovery and inventory. The accepted text is that of proposal 7, version 2.

Reason: Before asking whether to dig, one must know what can be recovered; the Article does not authorise new extraction. Code 10, Arts. 3 and 7 (inventory and access to the Land Register) aligned.

Discussion: no comments received by 19 October 2026 (issue 15).

19 October 2026 — Code 7, Art. 1, para. 2, new letter f), and new Art. 6-bis; Code 1, Art. 8, para. 3 (proposal 8)

Robots and autonomous machines. The accepted text is that of proposal 8, version 2.

Reason: No text governed machines that act on their own among people. Code 1, Art. 8, para. 3 aligned.

Discussion: no comments received by 19 October 2026 (issue 16).

19 October 2026 — Code 1, Art. 44, para. 3; Art. 45, paras. 2 and 3 (proposal 9)

Decay of the CdR. The accepted text is that of proposal 9, version 2.

Reason: The text did not say how the value of CdR decreases; the gradual reduction respects both the twelve months and the twenty-fourth month.

Discussion: no comments received by 19 October 2026 (issue 17).

19 October 2026 — Code 1, Art. 44, para. 2 (proposal 10)

CdR cap and supplements. The accepted text is that of proposal 10, version 2.

Reason: The text did not say whether the cap also applies to supplements, nor how the balance is measured.

Discussion: no comments received by 19 October 2026 (issue 18).

19 October 2026 — Code 3, Art. 7, para. 3 and new paras. 3-bis and 3-ter; Art. 7-bis, para. 1; Art. 21, para. 3 (proposal 11)

Economic thresholds in proportion to the size of the Community. The accepted text is that of proposal 11, version 2.

Reason: The same fixed thresholds weighed very differently in a Community of thirty people and in one of five hundred. Art. 21, para. 3 aligned.

Discussion: no comments received by 19 October 2026 (issue 19).

Versions: Code 1 from V1.5 to V1.6, C.1-Annex A from V1.3 to V1.4, Code 3 from V1.4 to V1.5, Code 5 from V1.3 to V1.4, Code 7 from V1.6 to V1.7, Code 8 from V1.3 to V1.4, Code 10 from V1.3 to V1.4, Code 15 from V1.3 to V1.4. The Constitution remains at V.29. The proposals had been open since 6 October 2026 (proposal 2 since 19 October); when nobody answers, the register says so instead of writing “approved after discussion”.

5 October 2026 — Constitution, Art. 6.5 (material correction)

“In Communities with fewer than one hundred and fifty persons” becomes “In Communities with fewer than one hundred and fifty persons entitled to vote”.

Reason: for the same threshold Code 3, Art. 12-bis, para. 12, counts those entitled to vote, while the Constitution counted persons. The measure of the Code has been kept, because the Councils are made up of persons drawn by lot from among those entitled to vote: it is their number that tells whether a Community can fill them. The version remains V.29.

How the rules change

From 19 October 2026 verified changes are applied directly and recorded on this page with the date, the text and the reason. The eleven proposals published between 5 and 19 October have been accepted and can still be consulted in the archive of proposals. Anyone can report a problem or propose a change: see How to contribute.
