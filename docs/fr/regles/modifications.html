Registre des modifications

Ceci est la première version publique : Constitution V.29 et Codes alignés, publiés le 5 octobre 2026.

À partir de maintenant, chaque modification acceptée sera notée sur cette page avec la date, le texte et l’article concernés, et la raison.

Modifications

19 octobre 2026 — C.1-Annex A, art. 4, al. 1 et 3, et nouvel al. 1-bis ; Code 1, art. 32, nouvel al. 1-bis (proposition 1)

Vêtements et hygiène dans le Panier matériel. Le texte accepté est celui de la proposition 1, version 2.

Raison : Les vêtements et les produits d’hygiène sont nécessaires à chacun, et aucun Panier ne les nommait.

Discussion : aucune observation reçue au 19 octobre 2026 (signalement 9).

19 octobre 2026 — Code 1, nouvel art. 47-bis (proposition 2)

Normes du logement adéquat. Le texte accepté est celui de la proposition 2, version 4.

Raison : La Constitution garantit le logement, mais aucun texte ne disait ce qui le rend adéquat.

Discussion : aucune observation reçue au 19 octobre 2026 (signalement 10).

19 octobre 2026 — Code 7, art. 3, nouvel al. 9 ; Code 5, art. 2, nouvel al. 4-bis (proposition 3)

Connectivité et matériel pour apprendre. Le texte accepté est celui de la proposition 3, version 2.

Raison : La connectivité est un droit, mais le Code 7 ne disait pas avec quoi on l’exerce.

Discussion : aucune observation reçue au 19 octobre 2026 (signalement 11).

19 octobre 2026 — Code 8, art. 4, al. 4 (proposition 4)

Valeur de première application du Panier énergie. Le texte accepté est celui de la proposition 4, version 2.

Raison : Le Panier énergie énumérait les services garantis sans aucune valeur minimale.

Discussion : aucune observation reçue au 19 octobre 2026 (signalement 12).

19 octobre 2026 — Code 1, art. 43, nouvel al. 1-bis (proposition 5)

CdR pour les activités culturelles offertes à la Communauté. Le texte accepté est celui de la proposition 5, version 2.

Raison : Ce qu’une personne offre à tous est une contribution ; le décompte en heures et la limite annuelle évitent qu’elle devienne un classement.

Discussion : aucune observation reçue au 19 octobre 2026 (signalement 13).

19 octobre 2026 — Code 10, art. 1, al. 1, 2 et 3 ; art. 9, al. 1, lettre a) (proposition 6)

Le sous-sol, bien commun. Le texte accepté est celui de la proposition 6, version 2.

Raison : Aucun texte ne nommait le sous-sol et les gisements ; désormais on ne peut pas en tirer de rente.

Discussion : aucune observation reçue au 19 octobre 2026 (signalement 14).

19 octobre 2026 — Code 10, nouvel art. 8-bis et art. 3 et 7 ; Code 15, art. 12, nouvel al. 5-bis (proposition 7)

Matières premières : récupération et inventaire. Le texte accepté est celui de la proposition 7, version 2.

Raison : Avant de se demander s’il faut creuser, il faut savoir ce que l’on peut récupérer ; l’article n’autorise pas de nouvelles extractions. Code 10, art. 3 et 7 (inventaire et accès au Cadastre) alignés.

Discussion : aucune observation reçue au 19 octobre 2026 (signalement 15).

19 octobre 2026 — Code 7, art. 1, al. 2, nouvelle lettre f), et nouvel art. 6-bis ; Code 1, art. 8, al. 3 (proposition 8)

Robots et machines autonomes. Le texte accepté est celui de la proposition 8, version 2.

Raison : Aucun texte ne réglait les machines qui agissent seules parmi les personnes. Code 1, art. 8, al. 3 aligné.

Discussion : aucune observation reçue au 19 octobre 2026 (signalement 16).

19 octobre 2026 — Code 1, art. 44, al. 3 ; art. 45, al. 2 et 3 (proposition 9)

Décroissance de la CdR. Le texte accepté est celui de la proposition 9, version 2.

Raison : Le texte ne disait pas comment diminue la valeur des CdR ; la réduction progressive respecte à la fois les douze mois et le vingt-quatrième mois.

Discussion : aucune observation reçue au 19 octobre 2026 (signalement 17).

19 octobre 2026 — Code 1, art. 44, al. 2 (proposition 10)

Plafond de la CdR et majorations. Le texte accepté est celui de la proposition 10, version 2.

Raison : Le texte ne disait pas si le plafond vaut aussi pour les majorations, ni comment se mesure le solde.

Discussion : aucune observation reçue au 19 octobre 2026 (signalement 18).

19 octobre 2026 — Code 3, art. 7, al. 3 et nouveaux al. 3-bis et 3-ter ; art. 7-bis, al. 1 ; art. 21, al. 3 (proposition 11)

Seuils économiques proportionnés à la taille de la Communauté. Le texte accepté est celui de la proposition 11, version 2.

Raison : Les mêmes seuils fixes pesaient très différemment dans une Communauté de trente personnes et dans une Communauté de cinq cents. Art. 21, al. 3 aligné.

Discussion : aucune observation reçue au 19 octobre 2026 (signalement 19).

Versions : Code 1 de V1.5 à V1.6, C.1-Annex A de V1.3 à V1.4, Code 3 de V1.4 à V1.5, Code 5 de V1.3 à V1.4, Code 7 de V1.6 à V1.7, Code 8 de V1.3 à V1.4, Code 10 de V1.3 à V1.4, Code 15 de V1.3 à V1.4. La Constitution reste à la V.29. Les propositions étaient ouvertes depuis le 6 octobre 2026 (la proposition 2 depuis le 19 octobre) ; quand personne ne répond, le registre le dit, au lieu d’écrire « approuvée après discussion ».

5 octobre 2026 — Constitution, art. 6.5 (correction matérielle)

« Dans les Communautés comptant moins de cent cinquante personnes » devient « Dans les Communautés comptant moins de cent cinquante personnes ayant le droit de vote ».

Raison : pour le même seuil, le Code 3, art. 12-bis, al. 12, compte les ayants droit au vote, tandis que la Constitution comptait les personnes. On a gardé la mesure du Code, parce que les Conseils sont composés de personnes tirées au sort parmi les ayants droit au vote : c’est leur nombre qui dit si une Communauté peut les pourvoir. La version reste V.29.

Comment les règles changent

Depuis le 19 octobre 2026, les modifications vérifiées sont appliquées directement et enregistrées sur cette page avec la date, le texte et la raison. Les onze propositions publiées entre le 5 et le 19 octobre ont été acceptées et restent consultables dans les archives des propositions. Chacun peut signaler un problème ou proposer une modification : voir Comment contribuer.

Paramètres à vérifier

Ce sont des nombres proposés pour rendre les règles applicables. Tous peuvent être modifiés par procédure ordinaire. Les données et les expériences qui les confirment ou les démentent sont les bienvenues. Le registre complet, avec l’origine de chaque valeur, son incertitude et la preuve qu’il faudrait pour la confirmer ou la corriger, est sur la page Paramètres à vérifier. C’est un brouillon de calibrage, non adopté, qui ne modifie aucune règle.
