Traduction de travail. Le texte de référence est l’italien.

Brouillon de calibration, non adopté. Cette page rassemble les nombres que proposent les textes et indique, pour chacun, d’où il vient et ce qu’il faudrait pour le confirmer ou le corriger. Elle ne modifie aucune règle : les valeurs restent celles qui sont écrites dans la Constitution et dans les Codes, et elles ne pourront devenir contraignantes que lorsque des données existeront et que les organes prévus pourront les approuver.

Comment le lire

  • Valeur proposée : le nombre écrit aujourd’hui dans les textes.
  • Siège : l’article où il se trouve.
  • Origine : une source extérieure, quand il y en a une ; sinon « choix de rédaction », c’est-à-dire un nombre fixé pour rendre la règle applicable, sans donnée qui l’étaye.
  • Incertitude : faible, moyenne ou élevée, selon que la valeur est plus ou moins étayée par des données et qu’elle peut plus ou moins changer d’un lieu à l’autre.
  • Preuve nécessaire : ce qu’il faudrait mesurer, calculer ou expérimenter.

Toute personne qui dispose d’une donnée, d’une expérience ou d’une critique peut ouvrir un signalement ou écrire à zerocirclesproject@gmail.com.

1. Paramètres avec des points de comparaison extérieurs

Pour ces valeurs, il existe des données ou des normes auxquelles se comparer. La comparaison ne les confirme pas : elle indique où regarder.

Paramètre Valeur proposée Siège Origine et points de comparaison Incertitude Preuve nécessaire
Limite du travail nécessaire (CBO) moyenne de 15 heures par semaine au plus, sur base trimestrielle Code 1, art. 3 Choix de rédaction. Un premier calcul fondé sur les besoins (brouillon de l’Annexe UCR) donne entre 9 et 13 heures par semaine, objets manufacturés compris. Avec le mode de production actuel, une étude indépendante estime à environ 27 heures le temps nécessaire pour un minimum réaliste. Élevée. C’est le paramètre dont dépend l’équilibre de tout le système. Bilans du travail réels ; heures mesurées dans les cuisines collectives, les potagers et les ateliers ; part du travail domestique qui entre dans la CBO.
Panier eau au moins 50 litres par personne et par jour Code 8, art. 4-bis L’OMS (2020) indique environ 20 litres comme accès de base, 50 litres comme accès intermédiaire à faible risque pour la santé, 100 litres comme accès optimal. Le standard humanitaire Sphere fixe un minimum de 15 litres dans les situations d’urgence et reconnaît qu’en ville il peut en falloir 50. Faible comme minimum sanitaire ; moyenne selon le climat et les usages locaux. Consommations réelles selon le climat et la saison ; disponibilité de la ressource sur le territoire. Signalement 6.
Taille de la Communauté de base en règle générale 30–500 personnes Const. 5.1 Le « nombre de Dunbar » (environ 150) est contesté : une revue de 2021 trouve des estimations comprises entre 16 et 109 avec des intervalles de confiance de 2 à 520, et conclut qu’indiquer un nombre est inutile. Dans les assemblées municipales du Vermont, environ 20 % des électeurs participent en moyenne dans les communes de moins de 5 000 inscrits. Élevée. Données de participation des assemblées, coopératives et écovillages, ventilées par taille. Signalement 4.
Seuil de la petite Communauté moins de 150 ayants droit Const. 6.5 ; Code 3, art. 12-bis, al. 12 Comme ci-dessus : le seuil de 150 n’a pas de fondement solide. Élevée. Vérifier en dessous de quelle taille on ne parvient plus à pourvoir tous les Conseils sans surcharger les personnes.
Quorum de l’Assemblée aucun pour les délibérations ordinaires ; 1/3 des ayants droit pour les décisions qualifiées ; 1/2 pour celles qui comportent des garanties spéciales Const. 35.1 ; Code 3, art. 12 Dans les assemblées du Vermont, la participation moyenne tourne autour de 20 % : un quorum d’un tiers est plus élevé que ce qu’atteignent habituellement les assemblées ouvertes. Élevée. Participation réelle dans des assemblées de taille comparable ; effet de la nouvelle publication prévue lorsque le quorum n’est pas atteint. Signalement 5.
Autonomie minimale du Noyau de soin 72 heures pour les biens vitaux et l’énergie Code 1, art. 39 Coïncide avec l’objectif de la stratégie européenne de préparation du 26 mars 2025 : autosuffisance de la population pendant au moins 72 heures. Faible comme minimum. Adéquation au climat et à l’isolement du lieu ; stocks effectivement nécessaires.
Validation des mesures conservatoires dans un délai de 24 heures Code 4, art. 34 Plus strict que le délai de la Constitution italienne (art. 13 : 48 heures pour la communication au juge et 48 pour la validation). Moyenne : le délai est protecteur, il faut vérifier qu’un organe tiré au sort parvient à le respecter. Cas d’essai sur le Code 4. Signalement 2.

3. Valeurs que les textes demandent et qui manquent

Les Codes renvoient à ces valeurs, mais aucun texte ne les fixe encore.

Ce qui manque Où c’est demandé Références de départ
Contenu du Panier de suffisance : biens, quantités, unités, période Code 1, art. 18 Proposé dans le brouillon de l’Annexe du Panier, avec les sources de chaque quantité.
Panier alimentaire : valeurs nutritionnelles et jours de stocks Code 9, art. 4 La valeur de planification utilisée par l’OMS, le HCR et le PAM dans les situations d’urgence est de 2 100 kcal par personne et par jour : c’est un minimum de survie, pas un niveau de vie.
Panier énergie : part minimale garantie Code 8, art. 4 Une étude de 2020 estime qu’une vie décente pour 10 milliards de personnes est possible avec moins de 40 % de l’énergie mondiale actuelle. Il faut la traduire en une part par personne et par climat.
Logement : surface minimale Const. 1.2 ; Code 10 Proposé dans la proposition 2, version 3 : au moins un séjour, une chambre et une salle de bains ; 30 m² pour une personne, 45 pour deux, 60 pour trois. La norme italienne sur l’habitabilité (décret ministériel du 5 juillet 1975) exige 28 m² pour une personne et 38 pour deux. Le standard Sphere pour les situations d’urgence est de 3,5 m² couverts par personne (4,5–5,5 dans les climats froids) : c’est un minimum d’urgence, pas un logement.
Mobilité de base : distances et temps garantis Code 11 ; Code 1, art. 25 Aucune référence pour l’instant.
Méthode de calcul de l’UCR Code 3, art. 9 Proposée dans le brouillon de l’Annexe UCR, avec un exemple détaillé.
Barème public de la CdR Code 1, art. 46 Modèle proposé dans le brouillon du barème. Il est local : chaque Communauté l’approuve.
